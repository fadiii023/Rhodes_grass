# RhodesGrass Export Frontend

Static 8-page frontend based on the supplied design reference.

Pages:
- Home
- About Us
- Rhodes Grass
- Quality
- Export Markets
- Export Process
- Resources
- Contact / Request a Quote

Important:
- All website photos are referenced directly in HTML using normal `<img>` or CSS background-image paths.
- JavaScript is only used for the mobile navigation and active-link highlighting.
- The included photo assets were extracted from the supplied design mockup so the frontend visually follows the reference.
- Replace the placeholder contact details and connect the quote form to your preferred form/email service before production.
